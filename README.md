# ✈️ Visora Travel Management App
[https://visoraappfinal-1.vercel.app/]

A modern web application built to manage tourism company accounts, employee tasks, and financial calculations seamlessly.

## 🎨 Features
* **Intuitive UI/UX:** Designed for ease of use and maximum productivity.
* **Smart Calculations:** Automates expense and profit calculations.
* **Staff Management:** Keeps track of employee transactions.

## 🛠️ Technologies Used
* HTML, CSS, JavaScript
* Firebase (Authentication & Database)
* Custom UI/UX Prototyping

*Developed with passion to bridge the gap between creative design and clean code.*
